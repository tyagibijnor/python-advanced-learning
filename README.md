# Python Advanced Learning 🐍

This repository is focused on advancing Python skills through practical examples and exercises. It covers core advanced programming concepts, with an emphasis on functional programming and object-oriented programming (OOP).

## Overview

The learning path in this folder is designed to help build a strong foundation in writing clean, reusable, and Pythonic code. The current focus is on:

- Functional programming techniques
- Lambda functions and higher-order functions
- Python OOP fundamentals
- Inheritance and method overriding
- Writing real-world problem-solving examples in Python

## Week 1 Topics

### Functional Programming

This section introduces core functional programming concepts such as:

- Lambda expressions
- `map()` and `filter()`
- `reduce()`
- Reusable functional patterns
- Writing concise and expressive Python code

### Object-Oriented Programming

This section explores the fundamentals of classes and objects, including:

- Class definitions
- Instance attributes and methods
- Constructor initialization using `__init__()`
- Encapsulation with validation
- Inheritance
- Method overriding
- Reusable class-based design

## Getting Started

Make sure you have Python 3 installed, then run any example script from its folder:

```bash
cd python-advanced-learning/w1/Functional-Programming
python lambda_functions.py
```

Or:

```bash
cd python-advanced-learning/w1/Object-Oriented-Programming
python oops-exercise.py
```

## Learning Goal

The goal of this track is to move beyond basic Python syntax and start thinking in terms of reusable patterns, cleaner abstractions, and real-world software design.
