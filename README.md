# Python Advanced Learning

A practical learning path for advanced Python concepts, organized by week and day.

## Week 1: Python Fundamentals

- **Day 1 — Functional programming:** employee salary analytics, lambdas, `map`,
  `filter`, and `reduce`.
- **Day 2 — Object-oriented programming:** employees, inheritance, departments,
  and unit tests.
- **Day 3 — Advanced functions:** reserved for upcoming lessons.

## Run the examples

Run commands from the relevant day folder:

```bash
cd week-01-python-fundamentals/day-01-functional-programming
python employee_salary_analytics.py
```

```bash
cd week-01-python-fundamentals/day-02-object-oriented-programming
python main.py
python -m unittest -v
```

All current examples use only the Python standard library. See
[`requirements.txt`](requirements.txt) for dependency information.
