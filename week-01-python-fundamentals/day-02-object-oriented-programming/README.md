# Day 2: Object-Oriented Programming

This lesson separates the employee hierarchy and department functionality into
small modules:

- `Employee` provides salary validation, salary increases, and a base bonus.
- `Manager` and `Developer` demonstrate inheritance and method overriding.
- `Department` groups employees and totals their salaries.

Run the demo and tests from this folder:

```bash
python main.py
python -m unittest -v
```
